# Panasonic-S5-flash-with-real-time-preview-
为松下s5添加闪光灯状态下的实时预览功能，按fn2键切换预览状态

功能：在「强制闪光开」或「强制闪光开/红眼降低」模式下，按一下fn2切换到实时预览状态，该状态下可调整快门光圈iso，实时看到变化，半按快门对焦或再次按下fn2退出状态（其他操作，比如打开菜单也会退出，待实测）
相机设置：
  1. 打开机身菜单中的「始终显示预览」，设为 `ON`。
  2. 进入「始终显示预览 → SET → 效果」，选择「A模式：光圈，M模式：光圈和快门速度」。
  3.打开Fn按键设置，将Fn2设置为「OFF无设置」或「OFF关（禁用按住）」。
注意：
  1.只实测了「强制闪光开」「强制闪光开/红眼降低」「强制闪光关」模式。其余两种闪光模式未实测，使用时可能出现预览或引闪异常。
  2.在 ISO 51200 已到上限的情况下继续往增大方向拨，机身仍会退出实时预览。
  3.在闪光灯未开启高速同步时，即使在实时预览状态下将快门速度调整至250以上，取消闪光预览时快门速度仍会自动变为250。
